# CateMate 合成数据演示

本目录仅保存对外展示所需的脱敏材料。所有类目、商品、站点、指标与链接均为合成演示数据，不对应任何雇主、生产系统或真实经营数据。

## 演示路径

1. 输入自然语言需求：分析 PH 宠物配件类目中“智能喂食器”相关商品的月度趋势与头部 SKU。
2. 在 Gate A0/A1 确认类目、时间范围和业务假设。
3. V2 Solve Loop 将已确认 Scope 与已激活的确定性 Data Module 绑定并执行。
4. 输出 Data Workbook、运行 manifest、Gaps，以及可选的 Brief/HTML 报告。

未覆盖的指标不会由模型补写，而会记录到 Gaps 中，供用户补充数据或后续扩展模块。
